# num-sim 设计规划

轻量级 Machinations：本地 localhost 数值沙盘，用于在落地 Luban 配置前，先在节点图上推演数值进程与生命周期。

## 1. 定位与边界

| 维度 | 定位 |
|---|---|
| 对标 | Machinations 的核心 20%（节点 + 连线 + tick 推进 + 曲线），砍掉其 80% 学习成本 |
| 不是什么 | 不是 Luban 替代品、不是精确战斗模拟器、不做多人协作 |
| 是什么 | 数值策划阶段的"草稿纸 + 计算器"：快速验证经济闭环/成长节奏，结论可信后再落到 Luban |
| 第一版场景 | 通用经济循环（产出 → 池 → 消耗/转换 → 门槛分支） |

## 2. 总体架构

```
┌─────────────────────────────────────────────┐
│  浏览器 (http://localhost:8787)              │
│  ┌────────────┬───────────────┬───────────┐ │
│  │ Luban 表   │  Canvas       │ 属性面板  │ │
│  │ 浏览器     │  节点编辑器   │ + 曲线图  │ │
│  └────────────┴───────────────┴───────────┘ │
│        纯前端 JS，无框架，无构建步骤         │
└──────────────────┬──────────────────────────┘
                   │ HTTP (127.0.0.1 only)
┌──────────────────┴──────────────────────────┐
│  server.js — Node 零依赖                    │
│  · 静态文件服务                             │
│  · GET /api/list?dir=   列目录(白名单扩展名)│
│  · GET /api/file?path=  读文件(json文本/   │
│                          xlsx二进制)        │
└─────────────────────────────────────────────┘
```

**选型理由**：
- 不用 exe：节点拖拽/连线 UI 在浏览器 Canvas 里开发量最小，双击 `start.bat` 即用，迭代不用重新打包
- 不用 npm 依赖：server.js 只用 Node 内置模块；xlsx 解析用 SheetJS（CDN，前端加载，失败时优雅降级为仅支持 Luban json 输出）
- 只监听 127.0.0.1：本机工具，不开外网

## 3. 核心模型（Machinations 最小子集）

### 3.1 节点类型（5 种）

| 节点 | 颜色 | 语义 | 关键属性 |
|---|---|---|---|
| **Source 产出源** | 绿 | 无限供给，每 tick 沿出边产出 | —（速率写在连线上） |
| **Pool 资源池** | 蓝 | 持有数值，可被绑定 Luban 表初始值 | `init` 初始值 |
| **Drain 消耗口** | 红 | 无限黑洞，每 tick 沿入边吞掉资源 | — |
| **Converter 转换器** | 黄 | 每 tick 从入边吃 `rateIn`，沿出边吐 `rateOut` | `rateIn`, `rateOut` |
| **Gate 条件门** | 紫 | 条件为真才放行其出边流量 | `condition` 表达式 |

### 3.2 连线

- **资源连线**（实线箭头）：`rate` 为**表达式**，变量一律按画布分配的唯一节点 id 引用（资源池 `n*`、公式 `f*`），名称仅作显示，例如 `n1*0.1`、`f1*(1+n4*0.05)`
- 方向即流向；从 Pool 出发的流量受池内余量限制（`min(rate, value)`）

### 3.3 表达式

- 运算符：`+ - * / ( )` 及比较 `>= <= > < == !=`、逻辑 `&& ||`
- 标识符支持中文（直接用 Pool 名当变量）
- 自研递归下降解析器（约 80 行，不用 `eval`，安全可控）

### 3.4 结算规则（每 tick）

1. 快照所有 Pool 当前值为表达式变量表
2. 按连线顺序结算资源连线（Source 无限供、Pool 限量供、Gate 条件拦截、Drain 吞掉）
3. 结算所有 Converter（先吃后吐）
4. 记录快照 → 供曲线图使用

> 注：这是"推模式"简化结算，与 Machinations 的 pull 模型在简单图上结论一致；复杂竞争边场景的差异在文档中显式说明，不作为精度承诺。

### 3.5 生命周期输出

- 每个 Pool 一条折线（值 vs tick），手绘 Canvas 图表（避免 CDN 依赖，离线可用）
- 结果可导出 CSV，方便拉回 Excel 二次分析

## 4. Luban 集成

| 功能 | 说明 |
|---|---|
| 目录浏览 | 输入本地路径（如 Luban 的 json 输出目录或 Excel 源表目录），列出 `.json/.xlsx/.xls/.csv` |
| 表预览 | json：自动定位首个数组字段作为数据行；xlsx：SheetJS 解析首个 sheet |
| 数值绑定 | 点击表中某单元格 → 一键绑定到「选中 Pool 的 init」或「选中连线的 rate」 |
| 设计理念 | 模拟器不直接消费 Luban 二进制，只读**人可读的 json/源表**，与 Luban 流水线解耦 |

## 5. 项目结构

浏览器原生 ES 模块，无构建步骤。分三层，依赖方向单向：`ui → app → core`，core 不依赖 DOM。

```
num-sim/
├── DESIGN.md / server.js / start.bat / index.html(仅页面骨架)
├── css/app.css
├── js/
│   ├── main.js              ← 入口：装配各模块、首次加载
│   ├── examples.js          ← 预置示例图
│   ├── core/                ← 纯逻辑，可在 Node 中直接运行与测试
│   │   ├── util.js          ← 数字/主键/随机数等纯函数
│   │   ├── expr.js          ← 表达式解析器（依赖通过 scope 注入）
│   │   ├── parse.js         ← json / csv / Luban ##var 源表解析
│   │   ├── tables.js        ← TableStore：按主键索引的数据表仓库
│   │   ├── model.js         ← Graph 模型、旧版本迁移
│   │   ├── validate.js      ← 校验与编译 → V
│   │   ├── sim.js           ← Simulator：按 tick 结算行为
│   │   └── edit.js          ← 图编辑操作（只改数据、返回结果）
│   ├── io/loader.js         ← 经 server.js 读目录/文件、加载 SheetJS
│   ├── app/
│   │   ├── state.js         ← 全局状态 S + 事件总线 on/emit
│   │   └── actions.js       ← 应用操作：调用 core → 持久化 → 发事件
│   └── ui/                  ← 各自订阅事件，彼此不直接调用渲染
│       ├── canvas.js  panel.js  chart.js  luban.js  autocomplete.js  toolbar.js  dom.js
│       ├── ports.js         ← 节点尺寸与端口布局（长方形节点，上入下出；由连线推导：已连 + 1 个空槽）与曲线几何/命中
│       └── menu.js          ← 通用右键菜单浮层
└── tests/
    ├── selftest.mjs         ← core 单元测试：node tests/selftest.mjs
    └── check-modules.mjs    ← 模块导入/导出与 DOM id 静态检查
```

事件：`graph`（图数据变化）、`select`、`panel`、`sim`（模拟结果）、`tables`、`loaded`（整图替换）、`fit`。

## 6. 编辑器交互（第一版）

- 左键拖节点移动；「连线模式」下点 A 再点 B 建边；「删除模式」点击即删
- 点选节点/连线 → 右侧属性面板编辑（名称/初始值/速率/条件）
- 顶部：tick 数输入、`运行`、`单步`、`重置`、`导出CSV`、图配置的`导出/导入 JSON`
- 图配置自动存 localStorage，刷新不丢

### 预置示例（通用经济循环，开箱可跑）

```
[产出源] ──10/tick──▶ [金币池] ──3/tick──▶ [日常消耗]
                         │
                         ▼ (Converter: 吃100 吐1)
                      [钻石池] ──Gate(钻石>=5)──▶ [十连抽消耗]
```

## 7. 迭代路线

| 版本 | 内容 |
|---|---|
| **v1**（本次） | 5 节点 + 表达式连线 + tick 模拟 + 曲线 + Luban 目录浏览/绑定 + CSV 导出 |
| v2 | 概率门（random p）、状态连线（条件触发开关节点）、tick 动画回放 |

## 8. 风险与取舍

| 风险 | 对策 |
|---|---|
| 结算语义与 Machinations 有差异 | 文档明示；v1 只承诺简单图结论一致 |
| xlsx 依赖 CDN（SheetJS） | 离线时降级为 json；Luban 本身就能输出 json，主路径不受影响 |
| 表达式写错导致模拟失真 | 解析失败即时红色报错定位到具体连线，运行时 NaN 熔断并提示 |
| 中文标识符边界情况 | 变量表按 Pool 名精确匹配，重名 Pool 在建图时禁止 |
